# Public navigation allowlist for the ARS documentation site.
#
# One `docs_dir`-relative Markdown path per line, in navigation order. This file
# is authoritative in both directions and `tools/check_docs_site.py` enforces
# three facts against `mkdocs.yml` and `website/docs/`:
#
#   1. every page reachable from `nav:` appears here;
#   2. every path here is reachable from `nav:`;
#   3. every Markdown file under `docs_dir` appears here — so a page cannot be
#      published by dropping a file into the tree and forgetting the nav.
#
# Publishing a page is therefore always a deliberate two-file edit. Internal
# roadmap, active plans, lessons, archives, superseded documents, and private
# runtime detail are not listed, are not reachable, and are not copied into the
# build output: they live under the repository's governed `docs/` tree, which is
# not this site's `docs_dir`.
